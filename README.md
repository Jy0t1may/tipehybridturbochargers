Electrified Hybrid Turbocharger Simulation & Testing (TIPE)

Overview
This repository contains the software, data visualizations, and hardware blueprints for an engineering research project (TIPE) designed to optimize automotive turbochargers. The goal is to reduce fuel consumption and emissions while increasing engine power through an electric-assist hybrid system.

Project Components
1. Mathematical Simulation (Python): 
    Focuses on the wastegate phase of the turbo cycle (battery tracking modules are currently scoped out for future iterations).
    Outputs consolidated fuel consumption charts demonstrating the continuous rise and zero-oscillation improvements of the electrified setup.

2. Interactive Web Dashboard:
    A front-end interface (HTML/CSS/JS) featuring live sliders and an accelerator wheel to manipulate physical parameters and visualize changes in real-time.

3. Hardware Prototyping:
    Documentation and 3D printing files for a physical testing assembly utilizing DC motors, a fan, and potentiometers to measure rotor voltage and speed.
  Technologies Used:
    Python (Data Visualization & Mathematical Modeling)
    HTML / CSS / JavaScript (Interactive Dashboard)
    3D Printing & Physical Electronics (Prototyping)
